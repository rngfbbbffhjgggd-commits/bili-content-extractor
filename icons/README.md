# 🎨 图标

给「B站一键提取」用的桌面图标。设计意图是**一眼看出这个工具在干什么**：

```
B站粉圆角底
 ├─ 白色屏幕 + 播放键      → 视频
 ├─ 三条横线（宽度递减）    → 转写出来的文本
 └─ 右下角下载角标          → 提取
```

| 文件 | 用途 |
|---|---|
| `bili_tool.ico` | 图标本体，含 16/24/32/48/64/128/256 七个尺寸 |
| `bili_tool_preview.png` | 256×256 大图预览 |
| `bili_tool_sizes.png` | 小尺寸可读性检查图（16/32/48/64 放大 3 倍，确认桌面尺寸下不糊） |
| `make_icon.py` | 生成上面三个文件的脚本（依赖 Pillow） |

## 怎么用

**想改设计**：编辑 `make_icon.py` 顶部的配色与坐标常量，然后：

```bash
python make_icon.py
```

三个文件会就地重新生成。

**想给桌面快捷方式换上它**：右键快捷方式 → 属性 → 更改图标 → 选 `bili_tool.ico`。

> ⚠️ 建议把 `.ico` **复制到一个稳定位置**再引用（例如 `%LOCALAPPDATA%\BiliContentExtractor\`），
> 不要直接指向项目目录——项目目录如果被移动、清理或受沙箱管辖，快捷方式就会显示成白纸。

**图标显示成白纸时**：先换一个图标文件路径（Explorer 的图标缓存按路径存，换路径会强制重新读取），
这比重启「Windows 资源管理器」温和得多。
