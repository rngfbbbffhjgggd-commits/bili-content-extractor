# 🎬 视频讲解稿

这是配套视频的**图文讲解文案**。你在视频里看到的每个环节，都可以回到这里对照着做。

## 本视频在讲什么

一个把 **B站 / YouTube 视频**变成**可读文本 + 可投喂的总结材料**的工具。

一句话打动你：**点开一个视频，一键拿到它的全文文字稿，再丢给 DeepSeek 免费得到一份详细总结。**

## 讲解提纲

### 1. 为什么做这个
- 看 B 站/YouTube 视频想看文字稿，但没有现成功能
- 想总结一个长视频（如讲座、教程、访谈），一点点看太累
- 这个工具帮你**0 token、本地、免费**搞定

### 2. 它怎么工作（核心逻辑）
```
视频链接 → 有字幕就下字幕 / 没字幕就本地转写 → 生成带时间戳全文 → 投喂 DeepSeek 网页版 → 免费总结
```
关键点：**有字幕就白嫖，没字幕才转写**，转写全程本地不花钱。

### 3. 三个让你放心的点
- **免费**：不消耗 API token（总结用网页版）
- **本地**：音频不出你的机器
- **多语言**：中/英/日/粤，最长 52 语言

### 4. 实操演示（视频后半段）
一步步演示：

1. 装环境：Python 3.10+、ffmpeg、`pip install -r requirements.txt`（见 [安装](/bili-content-extractor/install)）
2. 下模型：按视频类型挑（见 [模型下载](/bili-content-extractor/models)）
3. 配 cookie：一次性（见 [使用教程](/bili-content-extractor/usage)）
4. 跑起来：`python bili_quick.py "视频链接"`
5. 拿结果：得到 txt 和 **投喂 DeepSeek 网页版.md**
6. 丢进 DeepSeek：回车 → 拿到时间线总结

### 5. 适合哪些人用
- 学生/研究者：快速吃透长视频讲座
- 内容创作者：扒自己视频的字幕做二次创作
- 任何人：把「看」变成「读」，效率翻倍
